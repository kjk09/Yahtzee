# Yahtzee
A program which simulates a game of Yahtzee in the terminal.

# MVP
The basic version of this project will be fully terminal-based, local-multiplayer. Two or more players will take turns rolling dice, choosing dice to reroll, and then choosing the category in which to store their roll of the turn. These turns will cycle through until all players have filled all their categories/played 13 rounds, upon which point the program will determine the winner.

# Additional Features
Additional features to be added upon completion of the MVP include a simulated opponent for single-player games, a GUI through which to play the game, and the ability to save/load the same game over multiple sessions.

# Tech Stack
The program will be based in Java. I will need PrintWriter, BufferedReader, FileReader, and IOException to store game data. I may end up incorporating a TUI later on to improve terminal-based gameplay.
